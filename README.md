# 🧮 Modern Glassmorphism Calculator

A stunning, modern calculator application built with Vanilla JavaScript, HTML, and CSS. It features a premium **Glassmorphism** design, smooth animations, and a fully functional **Dark/Light mode** with local storage persistence.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-green.svg)

## ✨ Features

- **🎨 Modern Aesthetic**: Designed with the latest Glassmorphism trends, featuring blurred backgrounds, gradients, and subtle shadows.
- **🌗 Dark & Light Mode**: Seamlessly switch between themes. Your preference is saved automatically using Local Storage.
- **⚡ Responsive Design**: Fully responsive layout that looks great on desktops, tablets, and mobile devices.
- **🔢 Core Functionality**: Supports all basic arithmetic operations (`+`, `-`, `×`, `÷`, `%`).
- **🚀 Lightweight**: Built with pure HTML5, CSS3, and JavaScript - no external frameworks or heavy libraries.

## 🛠️ Tech Stack

- **HTML5**: Semantic markup for structure.
- **CSS3**: Advanced styling with CSS Variables, Flexbox, Grid, and Backdrop Filter.
- **JavaScript (ES6+)**: Logic for calculation and DOM manipulation.
- **Google Fonts**: Uses the [Outfit](https://fonts.google.com/specimen/Outfit) typeface for a clean, modern look.

## 🚀 Getting Started

To run this project locally, simply clone the repository and open `index.html` in your browser.

### Prerequisites

You need a modern web browser (Chrome, Firefox, Safari, Edge) that supports `backdrop-filter` for the best visual experience.

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/MAYANKSHARMA01010/Calculator-JS.git
   ```

2. **Navigate to the project folder**

   ```bash
   cd Calculator-JS
   ```

3. **Open the application**
   - Open `index.html` directly in your file explorer.
   - OR run with a local server like `Live Server` in VS Code for a better experience.
